# BRAWIJAYA — Platform Penangkalan Siber

Platform keamanan siber berbasis web untuk deteksi, pencegahan, dan respons ancaman.
Dibangun dengan HTML, CSS, dan JavaScript murni — tanpa framework, tanpa build step.

## ✨ Fitur

| Modul | Deskripsi |
|---|---|
| **Dashboard** | Ringkasan ancaman, IP diblokir, alert harian, playbook tereksekusi |
| **Smart IDS/IPS** | Simulasi alert stream, filter severity, pencarian, blokir IP, manajemen rules |
| **Threat Intelligence** | Pencarian IoC, tambah/hapus indikator, export CSV |
| **Incident Response** | Eksekusi playbook dengan log real-time |
| **Zero-Day Detection** | Analisis anomali dengan visualisasi dan tabel hasil |
| **Encryption Tool** | AES-256-GCM + PBKDF2 (Web Crypto API), Hash Generator |
